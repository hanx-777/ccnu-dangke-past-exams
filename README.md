# ccnu-dangke-past-exams

华中师范大学入党积极分子 / 党课考试历年真题与学习资料整理。

> 本仓库为非官方资料整理，仅供学习交流使用。
> 仓库内容主要来自公开资料、同学回忆整理与个人学习笔记，不代表学校或相关组织的官方立场。

## 简介

本项目用于整理华中师范大学入党积极分子培训、党课学习及相关考试的历年题目、参考答案和复习资料，方便同学进行考前复习与资料归档。

由于部分资料可能来自回忆整理，内容不保证完全准确。如发现错误，欢迎提交 Issue 或 Pull Request 修正。

## 仓库内容

本仓库内容包括但不限于：

- 历年真题、回忆版题目或整理版题目；
- 参考答案与解析；
- 题库（按题型分类）；
- 复习提纲、重点知识点和易错点；
- 其他与党课学习和考试复习相关的资料。

## 使用方式

你可以根据年份、资料类型或文件名查找需要的内容。

建议复习时优先查看：

1. 历年试卷（`papers/` 目录，按期号排列）；
2. 按题型分类的题库（`question-bank/` 目录）；
3. 复习提纲与重点知识点（`study-materials/` 目录）；
4. 参考答案与解析（`answers/` 目录）。

## 贡献方式

欢迎补充新的题目、答案或修正已有内容。详细说明请查看 [CONTRIBUTING.md](CONTRIBUTING.md)。

贡献前请注意：

1. 删除所有个人信息，例如姓名、学号、班级、手机号、QQ、微信等。
2. 不上传未经授权的内部文件、教材扫描件或其他可能存在版权风险的材料。
3. 如果题目来自回忆，请在文件中标注"回忆版"。
4. 如果不确定年份或来源，请在文件开头说明情况。
5. 如果不确定是否适合公开，请先不要直接提交到正式目录。
